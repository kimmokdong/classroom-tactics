# Classroom Tactics 안정화 결과

## 완료 단계

- 1~8단계: 전투 엔진, 증강체 계약, 저장/복원, 보드 평가, 가상 상대 AI, 접근성 안정화
- 9-1: 밸런스 시뮬레이션 설계
- 9-2: 다중 시드 실행 및 이상치 집계
- 9-3: 로그·시드 교란 수정과 최소 밸런스 조정
- 10단계: 기존 계약 기반 신규 증강체 추가

## 핵심 수정

- 전투 엔진: 처형 피해 로그가 실제 남은 체력만 기록하도록 수정
- 증강체: 설명과 무관한 p12 초과회복 효과 제거, `s12 자율학습 간식` 추가
- 테스트: 증강체 41종 계약, p12 조건, 처형 로그 회귀 검증
- 저장: 기존 ID 직렬화·복원 경로 유지
- 상대 AI: 기존 가상 로비 성장·전략 전환 유지
- 밸런스: 체육·육상·과학·보건부의 급격한 단계 수치 완화

## 검증 결과

- 테스트: `npm.cmd test` — 41개 통과
- 빌드: `npm.cmd run build` — 성공
- 시뮬레이션: 9-3 최종 5,400전 실패 0건
- 콘텐츠 축소 시뮬레이션: `reports/balance/10-content-smoke/` 36전 실패 0건

## 남은 위험

- 초반 `athletics`와 `broadcast`는 고정 실험 덱 상성의 영향이 커 추가 전역 너프를 보류했다.
- 신규 s12의 실제 경제 가치는 전체 런·상점 확률 시뮬레이션에서 재검증해야 한다.
- 브라우저 주요 화면과 기존 저장 데이터의 시각 검증은 별도 수동 QA가 필요하다.
