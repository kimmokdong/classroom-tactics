# Run Simulation Skill

## Trigger
유저가 "시뮬 돌려", "시뮬레이션 실행해 줘", "시뮬레이터 돌려" 등의 명령을 내릴 때 이 스킬을 실행하세요.

## Instructions
이 스킬이 발동되면 다음 단계를 **반드시 순서대로** 수행하세요.

1. **시뮬레이션 실행**
   - `run_command` 툴을 사용하여 워크스페이스의 루트 경로(예: `c:\Users\HSYJ\Desktop\classroom-tactics`)에서 `node run_simulation_v2.js` 명령어를 실행합니다.
   - 툴 호출 시 백그라운드 태스크(Task ID)가 완료될 때까지 기다리세요. (manage_task 활용)

2. **보고서 양식 기반 마크다운 텍스트 생성 (핵심 규칙)**
   - 시뮬레이션 완료 후 생성된 `simulation_report_v2.md` 파일을 읽고 분석하여, **반드시 아래의 목차와 템플릿 구조를 100% 동일하게 지켜서** 아티팩트용 마크다운 텍스트를 작성해야 합니다. 목차 하나라도 누락해서는 안 됩니다.
   - ⚠️ **분석 톤앤매너**: 분석 내용은 **굉장히 비판적인 태도로 날카롭게** 작성하세요. 특정 시너지나 유닛의 밸런스 붕괴 문제나 불합리한 점을 가차 없이 지적해야 합니다.
   - ⚠️ **기물 표기 방식**: 핵심 유닛 이름 옆에는 **반드시** 몇 코스트 몇 성인지 표시하세요. (예: `전교 학생회장(4코2★)`)

   ```markdown
   # 📊 교실 택틱스 v2 메타 리포트 분석
   > 🕒 **리포트 제출 시간**: [YYYY-MM-DD HH:MM:SS]

   ---

   ## 🏆 각 리그별 1티어 덱 요약 (승률 1위~3위)
   ### 🥇 Lv.7 미드게임 투기장
   (내용 채우기)
   ### 🥇 Lv.8 코어게임 투기장
   (내용 채우기)
   ### 🥇 Lv.9~10 극후반 투기장
   (내용 채우기)

   ---

   ## 🏆 무제한급 올스타 리그 랭킹 (Top 20)
   | 랭킹 | 승률 | 덱 명칭 | 🛡️ 핵심 3인방 (템 셋팅) |
   |---|---|---|---|
   (내용 채우기 - 무제한급 통합 리그 기준 상위 20개 덱)

   ---

   ## 1. 메타 분석 개요
   | 항목 | 내용 |
   |------|------|
   (총 덱 수, 시뮬레이션 방식 변화, 전반적인 메타 흐름 등)

   ---

   ## 2. 시너지 분석
   ### 📌 교과(Subject) 시너지 등장 횟수
   (표 형식)
   ### 📌 동아리(Club) 시너지 등장 횟수
   (표 형식)

   ---

   ## 3. 핵심 기물(유닛) 분석
   (전체 덱에서 공통적으로 자주 기용된 핵심 탱커/딜러/서포터)

   ---

   ## 4. 주요 발견 사항 및 밸런스 붕괴 지적
   ### ✅ 긍정적 변화
   ### ⚠️ 불합리한 점 / 밸런스 문제점 (비판적 어조 유지)

   ---

   ## 5. 밸런스 패치 제안
   ### 🔧 수치 조정 제안
   | 대상 | 조치 | 근거 |
   |------|------|------|
   (표 형식)

   ---
   ```

3. **아티팩트 업데이트 (UI 연동)**
   - 작성된 마크다운 텍스트를 반드시 **`write_to_file` 또는 `replace_file_content` 툴**을 사용하여 아티팩트 파일로 저장하세요.
   - `TargetFile`: `<현재 앱 데이터 경로>\brain\<현재 대화 ID>\latest_simulation_report.md`
   - `IsArtifact`: `true`
   - `Overwrite`: `true`
   - `ArtifactMetadata`: `{"ArtifactType": "other", "RequestFeedback": false, "Summary": "최신 시뮬레이션 분석 리포트"}`
   - **절대로** bash 명령어(`fs.writeFileSync` 등)로 아티팩트 파일을 덮어쓰지 마세요. 

4. **완료 보고**
   - 유저에게 시뮬레이션 완료 및 리포트 갱신 사실을 안내하고, 주요 변화를 요약해서 보고하세요.
